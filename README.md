# WEB бағдарламалау — электрондық оқу-әдістемелік кешен (ЭОӘК)

Интерактивная электронная книга УМКД: перелистывание страниц, оглавление, миниатюры, поиск по тексту,
масштаб, тёмная тема, полноэкранный режим, запоминание последней страницы.

**Технологии:** HTML · CSS · JavaScript (+ [page-flip](https://github.com/Nodlik/StPageFlip)) · Python (сборка из PDF)

## Структура
```
index.html        страница сайта
css/style.css     оформление (светлая/тёмная тема, адаптив)
js/app.js         логика: книга, поиск, оглавление, звук, масштаб
build.py          Python: PDF -> картинки WebP + текст для поиска -> data/data.js
data/toc.json     оглавление (редактируется вручную)
pages/            страницы, обычное качество (1400 px)
pages_hi/         страницы, высокое качество (2400 px, при увеличении)
umkd.pdf          исходный PDF
```

## Как обновить УМКД
```bash
pip install pillow          # и poppler-utils (pdftoppm, pdftotext)
python3 build.py новый.pdf  # пересоберёт pages/, pages_hi/, data/data.js
```
